# Write the Next Step Before Stopping

An open job with no written next step keeps running in your head. Three lines close it for now, and the next session starts without rebuilding context.

**Pattern:**
- Done: what is true now, with evidence.
- Stuck on: the one thing in the way, or "nothing".
- Next step: a time plus a first action, small enough to start cold.
