# Criteria before choice

Set the elimination criteria before reading the winning product's feature list.

1. Write non-negotiables, useful preferences, and the actual scenario. Include data handling, platform compatibility, licensing, and total cost when material.
2. Keep eliminated candidates in the comparison. Mark each criterion pass, fail, or unverified, with a dated source or observation. Marketing statements are claims, not integration tests.
3. Resolve the decisive unknown with the cheapest authorized experiment. Do not spend time scoring cosmetic preferences for an option that fails a required constraint.
4. Compare survivors on the same input and accepted outcome. Account for adapters, operations, and migration, not just request price.
5. State the recommendation, trade-off, remaining uncertainty, and trigger for revisiting it. A single successful example is not a broad reliability claim.

Use [the comparison example](examples/worked.md). Avoid universal model rankings: availability and capability change.
