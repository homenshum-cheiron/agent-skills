# Example: included cap and a hypothetical price (synthetic)

This is invented teaching data, not a reading from a real account.

A CLI run on a signed-in subscription shows 12% of a weekly included cap used, taken from the host usage page in the example. No overage line is present. A side calculation at public list prices, $0.40, is labeled hypothetical and is not reported as billed.

A later official invoice that showed overage would be reported as confirmed dollars. It would not stay in the sentence "still just subscription usage."

The report also names the host, a generic account class, the model, the effort, and the usage page as the source. If that page could not be opened, the example would say the path was unchecked instead of choosing a class.
