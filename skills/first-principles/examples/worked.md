# Example: skip the options memo (synthetic)

A checklist says to write a long options memo before any retry change. The actual need is a yes-or-no: may a failed digest be retried once?

The composed judgment leads with the decision. The unacceptable cost is a duplicate send. The memo does not help that decision, so it is skipped. The safety boundary still forbids a preview that sends real mail.

Fact: the request asks for one queue and no send. Judgment: a long comparison would delay a binary choice that already has a hard constraint. The vendor's daily cap stays unproven and is not papered over by the shorter answer.
