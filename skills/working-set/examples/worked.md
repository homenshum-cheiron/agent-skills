# Example: sixteen rows, then a handle (synthetic)

The active set for a digest-retry task already holds 16 one-line rows. Among them: the goal is "queue once and never send"; constraints are "no real mail" and "no spend"; one handle is `handler.ts:80` at synthetic SHA `abc1234`; an open claim says the vendor daily limit is unproven; the next action is to run the 409 fixture.

A 17th note, an old layout sketch, does not fit. It is evicted to `notes/layout` at `abc1234`, and that handle replaces it. The next-action row stays. The sketch is re-read only if a later step needs layout. Older design notes are not pasted into the prompt.

The count of 16 is a cap for this task, not a claim that a real session was measured.
